# Noaidi display

Copyright © 2026 Thor H. Linløkken <thj@thj.no>
License: CERN-OHL-S v2

The instrument's built-in screen, written in portable C with
[LVGL](https://lvgl.io) (v9.6, the `lib/lvgl` submodule). The same source
runs in the companion's simulated panel, compiled to WebAssembly, and is
meant to move unchanged into the hardware panel's firmware (an STM32 port).

## Layout

| Path | What | Portable |
|---|---|---|
| `include/noaidi_display.h` | the public API | yes |
| `include/noaidi_param_ids.h` | parameter IDs, generated by `companion/tools/gen_manifest` | yes |
| `src/` | the display: state, screens, labels and formats, theme | yes |
| `ports/web/` | Emscripten glue (`web_port.c`), the page (`shell.html`, `shell.js`), `make_html.py`, `lv_conf.h` | no: browser only |
| `test/display_test.c` | the portable display built natively, headless, with simulated touches | – |
| `lib/lvgl/` | LVGL, a git submodule | – |

`src/` includes only LVGL, the C library and its own headers;
`make portable` checks this. A port creates the `lv_display_t` and its
input device, drives `lv_tick` and `lv_timer_handler()`, and calls
`noaidi_display_init()`. Its `lv_conf.h` must enable RGB565 and the
Montserrat 14, 20 and 32 fonts.

## API

The caller speaks semantic parameters in musical units and owns the
control rules; the display decides how to show the outcome.

| Function | |
|---|---|
| `noaidi_display_init(disp)` | build the screen on a display the port created |
| `noaidi_display_set_value(param, value)` | a number value in its unit; ±`INFINITY` for special values |
| `noaidi_display_set_name(param, name)` | a name value (`"lowpass"`) |
| `noaidi_display_focus(param)` | show `param` prominently; `NOAIDI_PARAM_NONE` for the layer overview |
| `noaidi_display_set_layer(label, assignments[4])` | the current layer and what each encoder owns |
| `noaidi_display_set_event_cb(cb, user)` | hear `NOAIDI_DISPLAY_TOUCHED_PARAM` when the player taps a parameter |
| `noaidi_display_shown_value/focus/encoder_label` | what the screen shows, for tests |

## Building

```
git submodule update --init display/lib/lvgl
make -C display test          # native build and test
make -C display web           # needs Emscripten: source ~/emsdk/emsdk_env.sh
make -C display check         # test, portable, and the web build matches the checked-in page
```

`make web` writes `build/web/display.html` (open it in a browser) and
`companion/src/generated/displayHtml.ts`, the same page as a string for the
app. It is checked in, so building the app needs no Emscripten. The page
is self-contained (the WebAssembly is inlined as base64) and needs no
server or network. The build is reproducible with the same Emscripten
(6.0.10): a clean rebuild gives the same bytes.

The display is 480 × 320 RGB565 for now, a prototype size, not a choice of
panel (`WIDTH`/`HEIGHT` in the Makefile; the screen scales its layout).
